# رستا — رابط ورود و ثبت‌نام

رابط فارسی راست‌به‌چپ با React، Vite و Tailwind CSS برای API فعلی پروژه.

## اجرا

ابتدا سرور اصلی را با تنظیمات `.env` از ریشه پروژه اجرا کنید. سپس:

```bash
cd frontend
npm install
npm run dev
```

آدرس پیش‌فرض رابط `http://localhost:5173` است. Vite درخواست‌های `/api` را به `http://localhost:4000` می‌فرستد. اگر سرور در آدرس دیگری است، متغیر `BACKEND_URL` را هنگام اجرای Vite تنظیم کنید.

برای ساخت نسخه آماده انتشار `npm run build` را اجرا کنید. اگر رابط و API روی دامنه‌های جدا منتشر می‌شوند، `VITE_API_BASE_URL` را به آدرس پایه API تنظیم کنید.

اطلاعات حساب و توکن فقط در `sessionStorage` همین تب ذخیره می‌شوند و با خروج پاک می‌شوند. API فعلی `/api/v1/auth/me` هنوز پیاده‌سازی نشده است، پس رابط بعد از بارگذاری مجدد، اطلاعات نشست را از همین حافظه محلی می‌خواند؛ اعتبارسنجی تازه از سرور انجام نمی‌دهد.

## ساختار کد

- `src/components/`: اجزای مشترک رابط مانند لوگو، آیکن و فیلد ورودی
- `src/features/auth/`: صفحه و فرم‌های ورود/ثبت‌نام، ساخت دادهٔ درخواست و ارتباط با API
- `src/features/profile/`: نمایش اطلاعات حساب و دکمهٔ خروج
- `src/hooks/useSession.js` و `src/lib/session.js`: وضعیت نشست و ذخیره‌سازی آن در تب
- `src/App.jsx`: انتخاب صفحهٔ ورود یا پروفایل بر اساس نشست
